## Описание 

Проект использует генетический алгоритм для поиска оптимальной последовательности укладки коробок на паллету. Каждая коробка может быть уложена в одной из 6 возможных ориентаций, что позволяет минимизировать пустое пространство.

## Коробки и паллета
Каждая коробка имеет уникальный id, размеры (d1, d2, d3) и ориентацию.

Паллета имеет фиксированные размеры (x2, y2, z2) и  поддерживает укладку коробок с учётом их ориентации. Коробки укладываются как можно ближе к углу (0, 0, 0).

## Генетический алгоритм:

Хромосома: Последовательность коробок и их ориентаций.

Функция приспособленности: Отношение объёма уложенных коробок к объёму паллеты.

Мутация: Изменение порядка коробок и их ориентаций.

Кроссовер: Комбинирование двух хромосом для создания новой.

Селекция: Отбор лучших хромосом для следующего поколения.


## Запуск:
Настройки размеров паллеты, выбор номера файла находятся в файле default.toml

Запустить можно следующей командой:

   ```python3 src/main.py``` 

Установить число поколений и размер популяции можно в файле main.py (строчки 41, 42)

Установить зависимости можно следующей командой:

```pip install -r requirements.txt```
